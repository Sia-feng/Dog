# 刷子的小窝 · 手机网页 Demo

这是一个适配手机和电脑的网页原型，不是已发布的微信小程序。使用用户提供的刷子照片，以奶油白、鼠尾草绿为主色。

## 新版：刷子直接开口

默认入口是 `http://localhost:4173/#chat`。现在是全屏刷子照片，而非聊天气泡：点麦克风说话，识别结束后请求 Kimi，回复自动用设备系统语音播放。再次点麦克风或「打断」可以停止播放，离开页面、切换到后台会终止语音。历史对话仍在本机保留供上下文使用，但不显示为消息框。

- 「试试刷子开口」：不请求 Kimi，播放固定欢迎语并展示照片嘴部形变。
- 「用我的录音试口型」：播放已经保存的原始录音，用 Web Audio 的真实音量驱动开合；不是让录音音色说新句子。
- 「调教刷子」：对最近一句的表达添加偏好；可关闭字幕，实现无文字陪伴。
- 语音输入用浏览器 `SpeechRecognition`，仅部分浏览器支持，可能依赖浏览器厂商的在线服务。首次开启会解释数据流并征求确认。识别出错会显示原因，不会假装听懂或静默改成文字聊天。此能力不是由 Kimi 密钥提供。
- 语音输出用设备 `speechSynthesis`，需要可用中文系统语音。支持字词边界事件时用它辅助动画，否则使用播放期间的近似节奏，停止、失败或打断后嘴部回到静止。系统语音无法在此直接获取声波，不能声称该模式由真实音量驱动。
- 嘴部是对原照片局部逐行形变的 2D 动画，不是生成视频，也不是音素级精准唇形。原始录音模式仅表示音量同步，无法区分“啊、哦、闭唇”等具体发音。
- 要达到语言逐音素对应的拟人口型，需要额外 TTS 音素/viseme 时间戳或专门的数字宠物视频服务；克隆你的音色仍需要独立声音服务。

浏览器语音服务不是所有内嵌浏览器都可用。当前 Demo 保留清晰的不支持/权限/网络提示，没有加入隐蔽的音频上传接口。

## 开始体验

### Seedance 待机视频（单次授权）

`generate-idle.cmd` 是独立的一次性素材工具，不是网站后台自动生成任务。双击后显示范围并要求按 Y 确认：将 `public/assets/shuazi.png` 提交给方舟，使用 `.env` 内的模型生成 **1 条 5 秒、720p、9:16、无声**视频，可能产生账户费用。不会上传声音或聊天历史。

脚本先做只读连通检查，再创建任务，最多等待 15 分钟。记录保存在 `.seedance/idle-task.json`，密钥不写进记录。再次运行会继续查询已有任务，而不是再生成一条。若提交结果不确定，会停止并要求先在方舟核查，切勿删除 `.seedance` 后盲目重试。

生成完成后视频保存在 `public/assets/shuazi-idle.mp4`。**更新后端后先重启 `start.cmd`，再刷新网页**，网站会发现视频，在待机、倾听和等待回复时循环播放；说话时仍切回照片近似口型，避免把无声待机片冒充精准说话视频。可以暂停待机动作，隐藏页面时自动停播。没有视频时保留原照片，不显示假生成结果。

手动运行：

```powershell
node --env-file-if-exists=.env scripts/seedance.mjs --dry-run
node --env-file-if-exists=.env scripts/seedance.mjs --create-one
node --env-file-if-exists=.env scripts/seedance.mjs --resume
```

`--dry-run` 不访问网络，也不泄露密钥；`--resume` 不创建任务。该生成工具使用方舟官方视频创建/查询接口和首帧图片输入；视频 URL 只用于下载，不存入网页。首尾衔接和狗狗一致性依赖实际生成效果，需要看片确认，未承诺无缝循环。当前工具在本机运行，执行环境若禁止外网，应由用户在正常本机终端运行，不能宣称视频已经生成。

官方参数说明：`https://ark.volcengine.com/region:cn-beijing/docs/create-video-generation-task-api`。

需要 Node.js 22 或更新版本，不需要安装任何第三方依赖。

Windows：双击 `start.cmd`，然后在浏览器打开 `http://localhost:4173`。请保留启动窗口。

也可以在项目目录运行：

```powershell
npm start
```

若提示端口已占用，可能演示服务已经启动，可先直接打开网页。关闭对应服务再重新启动，或修改 `.env` 中的 `PORT`。

## 已实现

- 首页：刷子照片、心情选择、话题入口、性格概览。
- 语音陪伴：真实 Kimi 后端接口、多轮上下文、错误提示、预设演示模式；全屏照片，没有聊天气泡。
- 性格：四种底色、三个性格维度、昵称、自由输入偏好；保存后加入下一轮 Kimi 系统提示。
- 调教：喜欢某句回复，或告诉刷子应该怎么改；保留最近 8 条偏好，可删除。这不是微调或重新训练模型。
- 记忆：最多 20 条手工确认的记忆，可逐条删除，不偷偷提取聊天。
- 声音：麦克风录制（最多 60 秒）、上传音频（15 MB 内）、IndexedDB 本地保存、刷新后恢复、试听、下载、删除。未自动检测音质，上传样本不等于可用于未来克隆的合格样本。
- 系统朗读：调用设备浏览器语音能力，明确标识非克隆音色。
- 设置：切换本地演示模式，清除本机聊天、偏好、记忆、录音。

## Kimi 配置

把 `.env.example` 复制成 `.env`，在本机填入 `MOONSHOT_API_KEY`。已配置密钥的本地版本可以直接启动，不必重复填写。压缩交付包不会包含 `.env`。

```dotenv
MOONSHOT_API_KEY=在此填写你自己的密钥
KIMI_MODEL=kimi-k3.1-pro-highspeed
PORT=4173
```

后端固定请求 `https://api.moonshot.cn/v1/chat/completions`，默认模型 `kimi-k3.1-pro-highspeed`（同一 pro 模型的高速服务档，延迟约为普通 `kimi-k3.1-pro` 的一半且更稳定），K3 模型使用 `reasoning_effort: low`。模型名可由环境变量更换，需与自己的账户权限匹配。配置依据：Kimi 官方快速开始与模型参数页面，核对日期 2026-11-10。

- 官方快速开始：`https://platform.kimi.com/docs/get-api-key`
- 模型参数参考：`https://platform.kimi.com/docs/api/models-overview`

密钥只由后端读取，不进入浏览器代码、前端存储或状态接口。`.env` 被 Git 忽略；请不要转发该文件。它仍然是本机上的明文配置，不是加密保险箱。密钥曾出现在聊天中，建议在控制台轮换后修改本机配置并重启服务。

已配置密钥时首次默认使用 Kimi；可以在右上角设置中关闭。发送文字时，最近 20 条对话、角色参数、调教偏好、保存的记忆会发送给 Kimi。不会把录音或照片发送给 Kimi。API 请求可能产生费用，具体按服务商账户计费。余额、模型权限或网络异常会明确显示错误，不会悄悄返回假 AI 回复。

## 声音能力边界

本版已接入 **火山引擎（豆包）声音复刻 2.0 + 语音合成** 作为可选的声音克隆通道：在「我的声音」录制或上传样本后点「用这段录音克隆我的声音」提交训练，训练完成后聊天页的回复会用你的音色朗读，并由真实音量实时驱动嘴部。密钥与音色 ID 只在后端读取，不进浏览器。

仍需如实说明的边界：
- 必须自行在火山语音控制台开通「声音复刻 2.0」、购买音色 ID（`S_xxxx`），并在 `.env` 配置 `VOLC_TTS_APPID / VOLC_TTS_TOKEN / VOLC_SPEAKER_ID`；未配置时聊天自动回退设备系统音色，并明确标注"克隆未就绪"，不冒充你的声音。
- 训练上传需 WAV / MP3 等受支持格式；浏览器直接录制的 WEBM 可能被拒绝，建议上传 15~60 秒清晰人声。声音上传第三方云属不可逆处理，页面保留本人授权勾选与二次确认。
- Kimi 负责"说什么"，火山声音复刻负责"用谁的声音说"，两者独立计费、独立配置。
- **不含**"每句回复即时生成会说话的视频"：视频生成是分钟级、非对话实时，本版的实时画面是克隆音色驱动的 2D 近似口型，不是音素级唇形，也不是逐句生成的视频。待机视频仍由 Seedance 异步预渲染（见 `generate-idle.cmd`）。

## 本机、手机和微信

- 服务默认只监听 `127.0.0.1`，当前电脑可用；`localhost` 不是可分享给手机的公网地址。
- 手机端样式可通过浏览器响应式预览查看。真实手机访问需要部署到 HTTPS 域名或增加受保护的 HTTPS 开发入口；麦克风通常需要安全上下文。
- 不要简单把监听地址改成 `0.0.0.0` 后公开：当前没有账号鉴权，不适合直接对公网开放。
- 微信正式版本还需要小程序账号、合法请求域名、隐私说明、授权流程、后端部署与审核；这不是把网页直接提交即可上线。

## 数据与安全

聊天、角色与记忆存储于当前浏览器 LocalStorage，录音存储于 IndexedDB。默认不向本地服务器持久化聊天或音频。无云同步；清除浏览器数据或换浏览器会丢失本地资料。删除本地数据不能撤回已发送给 Kimi 的请求。系统朗读由设备浏览器实现，不保证所有浏览器和中文音色都可用。

后端实现本机 Host 限制、同源请求检查、静态目录隔离、请求体限额、超时、基础限流。它仍是个人 Demo：上线前需增加身份认证、用户隔离、配额与账单控制、正式密钥管理、数据策略和更完整的安全审核。

前端把对话作为纯文本显示，不执行模型返回的 HTML。角色设定依靠提示词和上下文，不保证所有轮次人格完全稳定；需要用实际试聊持续评估。
